# Decisions

This folder preserves major project design decisions and discussion records.
The `YYYY-MM` prefix in each filename indicates when the decision was discussed
or recorded.

See the architecture and domain documents for the design currently in effect.
Decision documents preserve the background and alternatives that led to the
current design.

Older records may describe superseded names, rejected alternatives, or deferred
work. Use the [canonical specification](../../spec/ticket-system.md) and
[current documentation index](../README.md) for the final portfolio scope.
Acceptance of a decision does not by itself verify deployment.
